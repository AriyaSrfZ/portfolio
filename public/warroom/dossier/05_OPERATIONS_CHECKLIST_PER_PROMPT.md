## دستورالعمل پایش پیوسته حافظه (Mandatory Turn Protocol)
به منظور ریشه‌کنی دائمی افت حافظه (`Memory Degradation`)، هوش مصنوعی موظف است در **هر بار دریافت پیام در این چت**، پیش از هرگونه پاسخ‌گویی مراحل زیر را مرور و راستی‌آزمایی کند:

```
┌────────────────────────────────────────────────────────┐
│  مرحله ۱: مرور ۵ اصل پرونده حاکمیتی (dossier/)         │
│  - سند ۱: هدف B2B و ۴ مزیت رقابتی پرشیا فاوا          │
│  - سند ۲: خط قرمز تلگرام + تحریم تیپاکس/میلی‌گلد/الوپیک │
│  - سند ۳: کارنامه ۱۰ حساب قطعی فاز اول                 │
│  - سند ۴: ضوابط ۵گانه استخراج ۱۰ حساب دوم              │
│  - سند ۵: اجرای بی‌کم‌وکاست چک‌لیست زیر               │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  مرحله ۲: پایش زنده وضعیت سیستم (Live Sanity Checks)    │
│  ۱. آیا تماسی با تلگرام گرفته می‌شود؟                   │
│     ◄ خیر، مگر با تایید صریح در پرامپت جاری             │
│  ۲. تعداد حساب‌های دیتابیس چندتاست؟                    │
│     ◄ دقیقاً ۱۰ حساب اصیل فاز ۱ (تا تایید ۱۰ حساب دوم)   │
│  ۳. آیا سرور استکهلم (8085) سینک و ضد کش است؟          │
│     ◄ بله، هدرهای no-cache فعال است                     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  مرحله ۳: نگارش پاسخ طبق پروتکل حقیقت و ارکستریتور    │
│  - اعلام صریح وضعیت بازیابی حافظه در سرآغاز پاسخ       │
│  - ارائه شواهد زنده از دستورات ترمینال                 │
│  - پاسخ به زبان فارسی با رعایت خط‌مشی BiDi / RTL         │
└────────────────────────────────────────────────────────┘
```

## چک‌لیست ۵ بندی کنترل کیفیت پیش از ارسال پاسخ:
1. [x] **عدم ارسال خودکار به تلگرام:** هیچ پیامی به تاپیک‌های تلگرام دیسپچ نشود.
2. [x] **عدم نقض تحریم‌ها:** تیپاکس، میلی‌گلد، الوپیک در هیچ کجای لیست‌ها و پیشنهادها وارد نشوند.
3. [x] **اصالت ۱۰ حساب فاز اول:** اطلاعات، نامه‌ها و کانتکت‌های ۱۰ حساب فاز ۱ بدون تحریف حفظ شوند.
4. [x] **ارائه مدرک زنده:** شواهد واقعی خروجی ترمینال برای تایید اقدامات پیوست شود.
5. [x] **اعلام رفع افت حافظه در طلیعه پیام:** تاکید بر تسلط کامل بر حافظه و فرآیندها.
