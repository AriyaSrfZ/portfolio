1. Direction in one line

Quiet editorial-technical: a flat tonal ladder on your Carbon base, one restrained accent (Patina), hairline borders instead of shadows, IBM Plex Mono for every number and label, and text carrying the page instead of decoration.

4. Typography (your fonts, used with a rule)

  • IBM Plex Sans: headings (600, -0.01em) and prose (400, 1.6 line height).
  • IBM Plex Mono: eyebrows (11px, uppercase, 0.1em tracking), tags, metrics (600, tabular numerals). Sanity uses this same pairing for its technical eyebrows.
  • Vazirmatn: Farsi pages, unchanged.
  • Remove all-caps from long headings; keep caps only on mono eyebrows.

5. Components

Card

4px radius, surface-1, one hairline, no shadow. Hover: hairline becomes hairline-strong. No glow, no beam.

Tag

Mono 11px, 2px radius, hairline border, ink-muted text. Replaces every pill.

Button, primary

Ink fill, canvas text, 4px radius. One per view.

Link

Patina, underlined at 3px offset. Hover goes to Patina light.

Icons: none by default. Where state must show, use a mono text label. If you later want icons, pick one 1.5px line set and approve it before it lands.
