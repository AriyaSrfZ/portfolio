3. Icons: remove the current style, do not replace it with another set

  • Remove every emoji and ✓/✕ glyph used as UI decoration (navbar theme check, dictionary tags, demo hero).
  • Remove the mixed Lucide icons from the two components where they appear.
  • Where a state must be shown, use a text label in the mono tag style (ACTIVE) or a 1px rule, not an icon.
  • Where an icon is truly needed (theme switch, external-link arrow), use a single 1.5px line set in one colour (n8), one size (16px). Confirm your preference before adding any set; the plan defaults to none.

4. Surfaces, shape and motion

  • Radius: 2px for tags and inputs, 4px for cards. Remove rounded-full except avatars.
  • Elevation: flat by default. One border, no shadow. Shadows only on the single modal/overlay layer.
  • Remove glassmorphism and backdrop-blur from navbar and cards; use solid n2 with a border.
  • Remove Aurora background, SpotlightCard glow, BorderBeam, and gradient overlays on the hero portrait.
  • Motion: remove animate-pulse and looping effects. Keep one 150ms colour transition on hover.

5. Typography (fonts unchanged)

  • IBM Plex Sans for prose and headings, IBM Plex Mono for metrics, tags and labels, Vazirmatn for Farsi.
  • Headings: weight 600, tracking -0.01em. Remove all-caps headings on long titles; keep all-caps only for mono labels.
  • Metrics: mono, tabular figures, n11 colour. This is the one place the page should look technical.
